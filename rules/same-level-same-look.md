---
id: same-level-same-look
title: Items at the same level look identical
severity: must
applies: [all]
check: review
since: 0.1.0
---

Siblings in a list, grid, nav, tag set or button group share one style. No rainbow tags, no per-card colours, no alternating accents.

- Differences between siblings must encode data (status, selection), and then use the state tokens with a text label.
- Category colour coding is allowed in charts and maps only, using `viz-*` in order.
