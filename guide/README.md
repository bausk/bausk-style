# Guidebook

How to make things that look and read like Oleksandr Bausk's work, in any medium, without the
generic look of machine-made design. This guide is versioned with the tokens: the copy inside a
project's installed `bausk-style` is the one that applies to that project.

## Reading order for agents

1. `bausk-style brief --media <m>` in the project. It prints the look, tokens, rules in force and
   the files below that matter for the task. Usually that is enough to start.
2. [anti-slop.md](anti-slop.md): what generic, machine-made design and copy look like, and what to
   do instead. Read it once per session.
3. The playbook for the medium: [reading](media/reading.md) (blog, articles, papers),
   [dashboard](media/dashboard.md), [slides](media/slides.md), [pptx](media/pptx.md),
   [figures](media/figures.md), [game](media/game.md), [video](media/video.md).
4. [voice.md](voice.md) for any text a reader will see.
5. [../rules/](../rules/) for the full text of a rule the brief names.

## Precedence

1. Accessibility floors and `must` rules.
2. Project rules: DESIGN.md "Project rules", `design/rules/*.md`, `bausk-style.json`.
3. The look (`LOOK.md` via the brief) and this guide.
4. Generic design skills and personal taste.
